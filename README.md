# 🔐 Password Strength Analyzer

A simple web-based tool that analyzes password strength in real-time and gives instant feedback to help users create stronger, more secure passwords.

## Features

- Real-time password strength checking
- Visual strength indicator (weak/medium/strong)
- Feedback on password criteria (length, uppercase, lowercase, numbers, special characters)
- Clean, single-page interface — no dependencies needed

## Tech Stack

- HTML, CSS, JavaScript (single file, no build tools required)
